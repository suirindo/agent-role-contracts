# Security policy

## Supported version

Security fixes are provided for the latest public release of Agent Role Contracts.

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Use the repository's GitHub private vulnerability-reporting / Security Advisory flow. Include the affected version, a minimal reproduction, impact, and any known workaround.

Agent Role Contracts v0.1.0 validates declarations only. Runtime identity, operating-system permissions, provider credentials, merge/deploy authorization and agent execution are outside this package.
